## Summary

Ticket: IR-1508. Spec-only PR #147 (head 36f59e5f, branch spec/ir-1508-native-decimal-ops, on origin/main 7200065) adding FR-403 and TC-951 (native Decimal operations over the FR-402 carrier) and a one-line pointer in FR-402. Reviewed against the owner source at origin/main 7200065: src/decimal.rs (evaluate, plan, Plan::expansion, arithmetic_sizes, intermediate, in_target_units, round, ExactLossValue::scaled, split_factor_five, Coefficient::lift/retain_charge/retain, reject_zero_divisor, expand_one, sbits, sdigits, Decimal::compare, compare_shifted), src/numeric.rs (order_numbers), src/integer.rs (magnitude_bits, decimal_digits, power_product_bits); FR-402, TC-950, FR-363, FR-362; Linear IR-1508. The literal AC values and charge amounts of AC-1 to AC-6 and AC-8 and the mutant inputs were recomputed with an independent Python model of the owner path (not the crate): all literal values agree with the owner. quire validate (spec/**/*.md) reports the same two FR-390 warnings as main and no new one; quire matrix adds FR-403-AC-1..12 as untagged (planned). No cargo, no Kani, no edits to the PR. Method: quoin spec-review/criterion-strength.

## Verdict

CHANGES REQUIRED. Jev (typesafe.ai System One) is not available here, so the 50 TC-951 mutant rows were checked by hand against owner semantics with an independent model. Rows that fail on their named input include: Add as Subtract, swapped Subtract, normalized retention, retention at operand scale, skipped lift, the na/ne tie rule, tz as floor, ties rounded up, proxy as zero, zero as rounding step, proxy loss, unfactored denominator, uncancelled twos/fives, wrapping doubled remainder, the divisor-test order, exact returns rounded, Inexact after rounding, out-of-domain after rounding, retain before membership, the expansion and sbits/sdigits amounts, the missing +1, Multiply max, rounding carries retain amounts, raw-coefficient ordering, le as lt, ge as gt, the shift/sum/product/negation/lift/power wraps, the proxy power formed, doubled before reduce, and Meter unchanged. Inspection rows have source checks. AC-11 and AC-12 refuse credit for non-completion and predictions. Failures: one equivalent mutant (FND-001), one missing control (FND-002), one input outside the case set (FND-003).

| FND-002 | medium | Behavior 5 requires the reduced numerator and the cofactor, and ground (e) the reduced remainder.
