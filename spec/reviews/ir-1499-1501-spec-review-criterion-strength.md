## Summary

Manual criterion-strength analysis (Jev client unavailable): can each AC fail for the defects and mutants the TCs claim? Ticket: IR-1499, IR-1500, IR-1501. agent-ix/quire-exact PR #145 (head de34959, two commits on origin/main), spec only: FR-399/TC-947 (non-metered `Text::from_admitted`), FR-400/TC-948 (payload-byte bound P per profile), FR-401/TC-949 (loop-free proof-path normalization). Scoped to `git diff origin/main...HEAD`. Checked against src/text.rs (admit_text, prepare, check_length, TextProfile::length, TextType::admits, NormalizationForm::apply, Text, TextPayload), Cargo.toml (`unicode-normalization` =0.1.25, test-support feature), the unicode-normalization 0.1.25 crate source (public `char::` API, private tables, TinyVec buffers), CG FR-052 on quire-contract-codegen origin/main, Linear IR-1445, IR-1436 (D4) and the IR-1501 lead ruling (2026-11-11). No builds or cargo runs. K_D = K_KD = 4, 36 attaining scalars (first U+1F82), the 18-scalar NFKD of U+FDFA and a longest canonical decomposition of 4 were re-derived independently with Python unicodedata (Unicode 16.0.0, not 17.0.0). IDs FR-399..401 and TC-947..949 collide with nothing on main or in open PRs (#144 holds FR-398/TC-946). `quire validate` passes on the six files and on the full spec tree (pre-existing EARS warnings on FR-390 only). `quire matrix` lists all 17 new ACs as untagged and FR-401-AC-3 as method-without-symbol.

## Verdict

**CHANGES REQUIRED** (1 high, 1 medium, 3 low). Jev (typesafe.ai System One) has no client in this environment, so this analysis was done by hand. Distinguishing as claimed: the TC-948 mutants (ratio 1, ratio +/-1, byte factor 3/5, wrapping multiply, filter-free nfkc, max-as-bound); the TC-947 mutants (meter, skipped retained check, payload-measured length, swapped measures, bound off by one, cause order, clone on non-empty payloads); and the TC-949 normalization mutants (reorder, blocked mark, exclusion, Hangul, compatibility, nfc-as-nfd, U+212B). The nfc/nfkc swap is correctly claimed nowhere in FR-400 and only on U+FB03 in TC-949. The FR-400 constants test is buildable from public API (`NormalizationForm::apply`, every non-surrogate scalar). It is not tautological, as long as the ratio is a stated constant (FND-004). Not distinguishing: the FR-401-AC-6 data-dependent-loop and loop off-by-one claims, and the FR-401-AC-3 closure and recursion bans.
