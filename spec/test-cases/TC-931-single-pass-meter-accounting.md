The named AC-12 log tests match the independent model for sampled ordered records, per-admission maxima, same-kind coalescing and refusal atomicity; the existing FR-358-AC-15 test covers the 4096-entry cap. The standalone baseline Kani proof must verify under its specified ceiling for three modeled charges plus the repeated-kind control, without log assertions; record the actual measured result for this exact configuration. The ALL-traversal control is expected to report the expected unwinding-assertion failure, and the refusal-order control to report the expected model-equivalence counterexample. Baseline `UnwindBoundExhausted`, `MemoryExhausted`, timeout, compiler error, missing mutation execution or a weakened symbolic domain, oracle or assertion set never counts as acceptance. All five unchanged consumer tests meet the individual `Verified` or `Falsified` verdicts in FR-359's AC-10 table and are recorded as an external receipt. An inconclusive result remains unaccepted even where FR-371-AC-6 classifies it as inconclusive for its broader qualification.
