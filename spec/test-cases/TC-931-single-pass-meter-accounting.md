## Expected Results

Charge processing has no traversal whose trip count exceeds the charge's semantic-size request count and preserves all previously observable accounting and denial behavior without a new count limit. The named AC-12 log tests match the independent model for sampled ordered records, per-admission maxima, same-kind coalescing and refusal atomicity; the existing FR-358-AC-15 test covers the 4096-entry cap. The three `units_proofs` harnesses must verify with every cover satisfied within 16 GiB and 600 seconds; record the measured result. The `min` mutant must fail at a named `consumed[k] matches` check and the `from_charge` mutant at `adapter keeps the second request`. Baseline `UnwindBoundExhausted`, `MemoryExhausted`, timeout, compiler error, missing mutation execution or a weakened symbolic domain, oracle or assertion set never counts as acceptance. All five unchanged consumer tests meet the individual `Verified` or `Falsified` verdicts in FR-359's AC-10 table and are recorded as an external receipt. An inconclusive result remains unaccepted even where FR-371-AC-6 classifies it as inconclusive for its broader qualification.
